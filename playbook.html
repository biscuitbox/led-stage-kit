막혔을 때 여는 곳

📖 초보 가이드북

WLED 접속법, 프리셋 저장법, 자주 나는 고장 17가지의 증상·이유·해결을 모았어요. 빠르게 찾으려면 워크벤치의 증상 고르기부터.

📶 1

WLED에 접속하기

  1. 와이파이 목록에서 WLED-AP를 고르고 비밀번호 wled1234를 입력해요.
  2. "인터넷 없음" 경고가 뜨면 연결 유지. 모바일 데이터는 잠깐 꺼요.
  3. 브라우저 주소창에 http://4.3.2.1 을 입력해요.
  4. 위쪽 전원 버튼과 밝기, 아래쪽 탭(Colors, Effects, Segments, Presets)이 보이면 성공. 한꺼번에 여러 명이 붙으면 끊기니 한 명씩.

만져도 되는 것

밝기, Effects(효과), 속도(Speed)·세기(Intensity), Colors·Palettes, Presets 저장. 마음껏 바꿔 보고 마음에 들면 새 이름으로 저장해요.

만지지 않는 것

톱니(Config) 안의 설정, 특히 LED Preferences(LED 수·출력 핀·색 순서)와 와이파이 설정. 바꿔야 할 것 같으면 선생님께.

💾 2

프리셋 저장하기

지금 화면 그대로 저장

  1. 효과·색·밝기를 원하는 대로 맞춰요.
  2. Presets 탭 → + Preset.
  3. 새 이름을 적고 Save.

AI가 준 명령으로 저장

  1. Presets 탭 → + Preset, 새 이름.
  2. Use current state 체크 끄기 → API command 칸.
  3. 검사기에서 받은 한 줄을 붙여 넣고 Save.

다른 사람 프리셋은 지우거나 덮어쓰지 않아요. 전시 효과로 정하는 것(부팅 시 적용, Playlist)은 선생님과 함께 해요.

🩺 3

자주 나는 고장 17가지

눌러서 펼치세요. 해결은 위에서부터 한 번에 하나씩, 전원은 끄고 해요.

1아무것도 안 켜진다
증상

전원을 넣었는데 100개 모두 꺼져 있어요.

이유

WLED 전원 버튼이 꺼져 있거나 밝기가 0, 또는 전원 공급이 끊겼거나 단자가 풀렸어요.

해결
  1. WLED 화면 위쪽 전원 버튼과 밝기 슬라이더를 확인해요.
  2. 컨트롤러 표시등이 꺼져 있으면 선생님께 어댑터·콘센트 확인을 부탁해요 (220V는 선생님만).
  3. 전원을 끈 상태에서 전원 입력 단자를 살짝 당겨 빠지지 않는지 봐요.
2한 지점부터 뒤가 전부 꺼지거나 멈춘다
증상

12번까지는 켜지는데 13번부터 끝까지 꺼져 있어요.

이유

신호(DATA)는 노드를 차례로 지나가요. 한 곳에서 끊기면 그 뒤로는 신호가 안 가요. 커넥터가 덜 꽂혔거나 그 자리 노드의 칩(IC)이 고장 났어요.

해결
  1. 마지막으로 켜진 노드와 첫 번째로 꺼진 노드 사이가 범인이에요.
  2. 전원을 끄고 그 사이 JST를 빼서 "딸깍" 소리 날 때까지 다시 꽂아요.
  3. 그대로면 두 노드 중 하나를 선생님과 교체해요. 번호는 연결 순서라 교체해도 설정은 그대로예요.
3불은 켜지는데 뒤쪽 몇 개가 말을 안 듣는다
증상

배선은 멀쩡한데 구간 끝 몇 개가 효과를 안 따라요.

이유

WLED에 적힌 LED 수가 실제 노드 수보다 적어요. WLED는 적힌 개수까지만 신호를 만들어요.

해결
  1. 배선을 건드리기 전에 설정부터 봐요.
  2. Config → LED Preferences에서 각 출력의 LED 수가 25인지 선생님과 확인해요.
4한 구간 전체가 반응이 없다
증상

다른 구간은 되는데 한 구간만 통째로 꺼져 있어요.

이유

단자대에 줄의 OUT 끝을 물렸거나, 그 출력의 DATA 선이 빠졌거나, 출력 핀 설정이 달라요.

해결
  1. 줄의 화살표를 보고 단자대에 물린 쪽이 IN 끝인지 확인해요.
  2. 단자대의 DATA 선을 살짝 당겨 봐요 (전원 끈 상태).
  3. LED Preferences의 출력 핀(GPIO 16·12·4·2)이 연결한 출력과 맞는지 선생님과 확인해요.
5노드 하나만 안 켜진다
증상

30번만 꺼져 있고 31번부터는 정상이에요.

이유

신호는 지나가는데 그 노드의 LED만 고장 났어요.

해결
  1. 번호를 기록하고 선생님께 알려요.
  2. 교체는 전원을 끄고 해요. 새 노드도 같은 자리에 꽂으면 같은 번호가 돼요.
6고른 색과 다른 색이 나온다
증상

빨강을 골랐는데 초록이 나와요.

이유

WLED의 색 순서(Color order)가 노드와 달라요.

해결
  1. LED Preferences의 Color order를 선생님과 함께 바꿔 봐요 (RGB, GRB, BRG 등).
  2. 배선을 건드리지 않는 설정 문제라 안전해요.
7깜빡이거나 제멋대로 켜진다
증상

특정 번호 근처에서 불이 튀거나 무작위로 번쩍여요.

이유

DATA 커넥터 접촉이 불안정해요. (전원을 둘 이상 쓸 때는 두 전원의 GND가 안 이어져도 생겨요. 우리는 어댑터 하나라 해당 없어요.)

해결
  1. 깜빡이기 시작하는 번호 근처 JST를 하나씩 끝까지 다시 꽂아요 (전원 끄고).
  2. 금속 핀이 보이면 덜 꽂힌 거예요.
8끝으로 갈수록 누렇고 어둡다
증상

1번은 하얀데 25번 쪽은 누렇고 떨려요.

이유

전선에도 저항이 있어서 멀리 갈수록 전압이 떨어져요(전압강하).

해결
  1. 구간 끝단 급전선이 풀리지 않았는지 선생님과 확인해요.
  2. 임시로 밝기를 낮추면 나아져요.
9켜자마자 잠깐 켜졌다 꺼진다
증상

번쩍 켜졌다가 바로 꺼지거나 컨트롤러가 다시 시작해요.

이유

전류가 모자라 보호 기능이 동작했거나, 어딘가 V+와 GND가 맞닿았어요(단락).

해결
  1. 밝기를 반으로 낮춰 다시 켜요. 살아나면 전원 용량 부족이에요.
  2. 안 살아나면 단락일 수 있어요. 손을 떼고 선생님을 불러요.
10만지면 켜졌다 꺼졌다 한다
증상

박스를 건드리거나 진동이 있으면 깜빡여요.

이유

커넥터가 헐겁거나 선이 팽팽해서 당겨지고 있어요.

해결
  1. 선이 팽팽한 곳을 찾아요.
  2. 전원을 끄고 다시 꽂고, 여유 루프를 남겨요.
11엉뚱한 박스가 켜진다 · 순서가 뒤섞였다
증상

5번을 켰는데 다른 자리 박스가 켜져요.

이유

연결된 순서가 곧 번호예요. 설치 순서가 기록과 달라요.

해결
  1. 번호 스티커와 순서 기록표를 대조해요.
  2. 순서를 바꿔 단 곳을 찾아 기록표에 맞게 다시 연결해요 (전원 끄고).
12어제는 됐는데 오늘은 안 된다
증상

켤 때마다 처음 효과로 돌아가거나, 어제 되던 곳이 꺼져 있어요.

이유

부팅 시 적용 프리셋이 지정되지 않았거나, 진동으로 커넥터가 풀렸어요.

해결
  1. 선생님께 LED Preferences의 "부팅 시 적용 프리셋(Apply preset at boot)"을 확인해 달라고 해요.
  2. 꺼진 곳이 있으면 커넥터를 하나씩 눌러 봐요.
13WLED-AP가 안 보인다 · 접속이 끊긴다
증상

와이파이 목록에 WLED-AP가 없거나 자꾸 끊겨요.

이유

컨트롤러가 꺼져 있거나, 여러 명이 동시에 접속했어요.

해결
  1. 컨트롤러 표시등을 확인해요.
  2. 한 번에 한 명만 접속하고, 나머지는 화면을 같이 봐요.
  3. 그래도 안 되면 선생님께 컨트롤러 재시작을 부탁해요.
14WLED-AP에 붙었는데 4.3.2.1이 안 열린다
증상

와이파이는 연결됐는데 주소를 쳐도 페이지가 안 떠요.

이유

휴대폰이 "인터넷 없는 와이파이"를 피해서 모바일 데이터로 보내고 있어요.

해결
  1. 모바일 데이터를 잠깐 꺼요.
  2. "인터넷 없음" 경고가 뜨면 "연결 유지"를 눌러요.
  3. 주소창에 http://4.3.2.1 을 정확히 입력해요 (검색창 말고 주소창).
15프리셋을 저장했는데 변화가 없다
증상

Save를 눌렀는데 불이 그대로예요.

이유

명령이 깨졌어요. ```json 표시까지 복사했거나, 따옴표가 “ ”로 바뀌었거나, 괄호가 빠졌어요.

해결
  1. 워크벤치의 "AI 답 검사하기"에 붙여 넣어 깨끗한 명령을 받아요.
  2. Use current state 체크를 껐는지 확인해요. 켜져 있으면 명령 대신 지금 상태가 저장돼요.
  3. 아이폰은 설정 → 일반 → 키보드 → 스마트 구두점을 끄면 따옴표가 안 바뀌어요.
16원한 것과 전혀 다른 효과 · 색이 한 가지만
증상

파도를 원했는데 번쩍이는 효과가 나오거나, 한 색만 나와요.

이유

효과 번호(fx)가 우리 WLED 목록과 다르거나, 팔레트가 0(Default)이라 첫 색만 써요.

해결
  1. 프롬프트에 우리 효과 목록을 넣었는지 확인하고, 목록에서 이름으로 번호를 찾아요.
  2. "팔레트를 정하거나 색을 2~3개 넣어 줘"라고 다시 요청해요.
17휴대폰에서 AI가 안 열린다
증상

AI 사이트가 로딩만 돼요.

이유

WLED-AP에 연결된 상태예요. WLED-AP에는 인터넷이 없어요.

해결
  1. AI는 LTE나 학교 와이파이에서 쓰고, 답을 복사한 다음 WLED-AP로 바꿔요.

✏️ 4

바로 쓰는 수정 요청 문장

AI의 답이 마음에 안 들 때 그대로 복사해서 이어 보내요.

좋아. 그런데 더 느리고 차분하게 바꿔 줘. 같은 형식으로 한 줄만 다시 써 줘.
한꺼번에 다 켜지지 말고, 100개 중 몇 개만 무작위로 서서히 켜지고 꺼지게 해 줘. 같은 형식으로 한 줄만.
네가 고른 fx 번호가 내가 준 효과 목록에서 몇 번째 이름인지 확인하고, 틀렸으면 고쳐서 한 줄로 다시 써 줘.
JSON 문법이 틀렸어. 코드 블록 표시 없이, 곧은 따옴표만 써서 한 줄로 다시 써 줘.

🛡️ 5

AI를 쓸 때 지킬 것

개인정보는 넣지 않는다

이름, 학교, 연락처, 얼굴 사진은 프롬프트에 넣지 않아요. 작품 설명과 원하는 장면만으로 충분해요.

AI는 틀릴 수 있다

효과 번호를 지어내기도 해요. 우리 목록과 검사기로 확인하고, 눈으로 켜 보고 판단해요.

안전은 AI에게 묻지 않는다

전원, 배선, 뜨거움, 냄새에 관한 판단은 AI가 아니라 선생님과 해요.

정하는 것은 사람

이 작품은 "내 무대의 불을 내가 켜는가, AI가 켜 주는가"를 묻습니다. AI의 답을 그대로 쓸지 고칠지는 여러분이 정해요.

📚 6

낱말 사전

노드

LED 하나와 칩(IC)이 든 작은 모듈. 박스 하나에 하나씩.

데이지체인

노드를 줄줄이 이어 신호를 차례로 넘기는 연결. 각 노드는 자기 몫만 쓰고 나머지를 뒤로 넘겨요.

IN · OUT

신호가 들어오는 쪽과 나가는 쪽. 줄의 화살표 방향이 흐름이에요.

V+ · DATA · GND

12V 전원, 신호, 접지. 선은 이 세 가닥뿐이에요.

JST 3핀

노드 사이를 잇는 커넥터. 모양이 맞아야만 꽂혀서 방향을 틀리기 어려워요.

단자대

나사로 선을 물리는 곳. 아무 선이나 들어가서 실수가 여기서 나요.

전압강하

전선 저항 때문에 멀리 갈수록 전압이 떨어지는 현상.

끝단 급전

줄의 끝에도 전원을 넣어 양쪽에서 받게 하는 방법.

ESP32 · WLED

ESP32는 와이파이가 든 작은 컴퓨터, WLED는 그 위에서 도는 조명 프로그램.

프리셋

효과·색·밝기 설정을 이름 붙여 저장해 둔 것.

팔레트

효과가 쓰는 색 묶음.

ABL

밝기 자동 제한. 전류가 너무 많이 흐르지 않게 막아 줘요.

빛으로 짓는 인생의 무대 · 이사벨여고 LED 조명 수업 학생용 키트 · 강사 마루나래
막히면 혼자 오래 붙잡지 말고, 증상을 적어서 선생님께 보여 주세요.
