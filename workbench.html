AI로 효과 바꾸기

AI는 새 효과를 발명하지 않아요. WLED 안에 이미 있는 100가지가 넘는 효과 중 말에 가장 가까운 것을 고르고, 속도·색·밝기 숫자를 정해 명령을 써 줍니다.

와이파이 순서가 핵심
WLED-AP에는 인터넷이 없어요. AI는 인터넷(LTE·학교 와이파이)에서 쓰고 → 답을 복사 → 와이파이를 WLED-AP로 바꿔 붙여 넣습니다. 복사한 내용은 와이파이를 바꿔도 남아 있어요.

0. 효과 목록 준비 (선생님이 나눠 준 목록이 있으면 건너뛰기)

  1. 와이파이 WLED-AP(비밀번호 wled1234)에 연결하고 브라우저에서 http://4.3.2.1/json/eff를 열어 전부 복사합니다. 효과 이름 목록이에요.
  2. 같은 방법으로 http://4.3.2.1/json/pal(팔레트 목록)도 복사합니다.
  3. 아래 칸에 붙여 두면 프롬프트에 자동으로 들어가고, 이 기기에 저장돼요.

목록이 비어 있으면 프롬프트에 [효과 목록 붙여넣기] 자리만 남아요.

1. 프롬프트 만들기



복사 → 인터넷 와이파이에서 AI(선생님이 정한 서비스)에 붙여넣기.



2. AI 답 검사하기


AI의 답을 통째로 붙여 넣고 검사하세요. 코드 블록 표시나 휜 따옴표(“ ”)는 자동으로 고쳐서, 붙여 넣을 깨끗한 한 줄을 만들어 줍니다.








3. WLED에 올리기


    

  1. 와이파이를 WLED-AP로 바꾸고 4.3.2.1을 엽니다.
    2. 

  2. 아래쪽 Presets 탭 → + Preset.
    3. 

  3. 이름은 "파도-1조"처럼 새 이름으로. 다른 사람 프리셋을 덮어쓰지 않아요.
    4. 

  4. Use current state 체크를 끕니다. 그러면 API command 칸이 나와요.
    5. 

  5. 검사기에서 복사한 한 줄을 붙여 넣고 Save.
    6. 

  6. 목록에서 그 이름을 누르면 바로 켜집니다. 고칠 때는 프리셋 옆 연필(편집) → API command 바꾸고 Save.
    7. 



연습용 명령 (Lake 효과 + Ocean 팔레트, 느리게). 효과 번호는 WLED 버전마다 다를 수 있어요.


{"on":true,"bri":140,"seg":[{"id":0,"fx":75,"sx":70,"ix":160,"pal":9,"col":[[0,80,255],[0,20,80]]}]}



4. 보고 고치기


말과 다르면, 어디가 다른지 AI에게 그대로 말하세요. 눌러서 복사:













숫자뜻직접 고칠 때



fx효과 번호효과 목록에서 0부터 센 순서. 이름으로 번호를 찾아요.


sx속도 (0~255)낮추면 느려져요. 작품에는 30~90 정도가 차분해요.


ix세기 (0~255)효과마다 다르지만 대개 켜지는 개수나 세기예요.


pal팔레트 번호0(Default)이면 col의 첫 색만 쓰는 효과가 많아요.


col색 [R,G,B]0~255. [0,80,255]는 파랑, [255,140,0]은 주황.


bri밝기 (0~255)우리 약속은 150 이하. 너무 밝은 건 ABL이 막아 줘요.




전시 효과로 쓰고 싶다면
선생님께 말하세요. 고른 프리셋을 부팅 시 적용으로 지정하거나, 여러 개를 Playlist로 묶어 돌아가며 켜지게 합니다. 전시장에는 전원만 있어서, 켜기만 하면 그 효과가 나와야 해요.








2
남은 박스 설치·결선


박스 방향이 기준이고, 선이 박스에 맞춥니다. 한 박스씩 끝까지 하고, 구간을 이을 때마다 켜서 확인해요.



박스 방향 규칙 6




1 박스마다 표시
윗면에 박스 번호와 "열린 면" 화살표 테이프.


2 박스를 먼저 제자리에
바닥 표시대로 놓고, 열린 면이 원 안쪽인지 본 뒤 노드를 답니다.


3 내 구간의 흐름 방향
오른쪽 절반은 시계 방향, 왼쪽 절반은 반시계. IN은 이전 박스 쪽, OUT은 다음 박스 쪽.


4 노드는 천장 정중앙
선은 옆면 구멍으로. 열린 면 쪽으로는 선이 지나가지 않아요.


5 층이 바뀌는 곳 조심
흐름이 반대로 돌아가도 박스는 돌리지 않아요.


6 선이 짧으면 멈추고 손 들기
박스를 돌려서 해결하지 않아요. 여유 루프나 연장선으로.





한 박스 다는 순서


    

  1. 장착 — 박스 천장 중심에 노드를 고정하고, IN·OUT 선을 흐름 방향대로 옆면 구멍으로 뺍니다.
    2. 

  2. 기록 — 번호 스티커를 붙이고 순서 기록표에 적어요. 연결된 순서가 곧 번호예요.
    3. 

  3. 한지 — 치수를 재고 열린 면에 한지를 붙여 빛을 부드럽게.
    4. 

  4. 배선 — 이웃 박스와 JST를 "딸깍" 소리 날 때까지 꽂고, 선에 여유 루프를 남깁니다.
    5. 

  5. 확인 — 구간을 이을 때마다 선생님이 전원을 켜고 WLED에서 새 박스까지 켜지는지 봐요.
    6. 




실수는 JST가 없는 곳에서 난다

3
고장 사냥


한 사람이 혼자 고치지 않아요. 순서대로, 한 번에 하나씩.



막혔을 때 다섯 단계


    

  1. 멈춘다 — 선생님이 전원을 끄고, 모두 손을 뗍니다.
    2. 

  2. 증상을 말한다 — "3번째부터 꺼져 있다"처럼 본 그대로.
    3. 

  3. 후보를 모은다 — 아래 증상 고르기나 가이드북에서 원인 2~3개.
    4. 

  4. 하나씩 확인한다 — 한 번에 하나만 바꾸고 켜 봐요. 한꺼번에 바꾸면 범인을 몰라요.
    5. 

  5. 한 문장으로 남긴다 — "JST가 반만 꽂혀 있었다." 고장 기록에 남겨요.
    6. 




증상 고르기


지금 보이는 것과 가장 가까운 것을 누르세요.







범인을 모르겠으면, 반으로 나눈다




하나씩 보면 최대 100번, 반씩 줄이면 7번이면 찾아요 (27 = 128).


    

  1. 전원을 끄고, 줄 가운데 커넥터를 빼서 그 뒤쪽을 컨트롤러에 직접 꽂아 봐요 (선생님과 함께).
    2. 

  2. 뒤쪽이 정상으로 켜지면 범인은 앞쪽, 아니면 뒤쪽.
    3. 

  3. 남은 쪽의 가운데에서 다시. 범위가 노드 1~2개가 될 때까지.
    4.
