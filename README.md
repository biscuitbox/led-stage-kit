# 빛으로 짓는 인생의 무대 — 학생용 키트

> 수업은 끝나도 작품은 계속 켜져 있습니다.
> 남은 박스를 달고, 효과를 바꾸고, 고장이 나면 고치는 일을 학생들이 스스로 할 수 있도록 돕는 사이트입니다.

이사벨여고 LED 조명 설치 수업(50분 × 3차시)의 후속 자료입니다. 학생 작품을 담은 나무박스 약 100개에 LED 노드를 하나씩 달아, 빛이 무작위로 서서히 켜지고 꺼지며 '인생'을 표현하는 설치 작품을 다룹니다.

**사이트 주소:** `https://biscuitbox.github.io/led-stage-kit/` (배포 후 실제 주소로 바꿔 주세요)

| 페이지 | 파일 | 하는 일 |

| 🛠️ 실습 워크벤치 | `workbench.html` | ① AI로 효과 바꾸기 ② 남은 박스 설치·결선 ③ 고장 사냥 |

## 주요 기능

### 🌊 AI로 효과 바꾸기
- **프롬프트 만들기**: 원하는 장면을 한 문장으로 적으면 WLED용 프롬프트가 완성됩니다. 예시 장면(반딧불이, 촛불, 별, 노을, 인생의 순간)을 눌러 바로 써 볼 수 있습니다.
- **효과·팔레트 목록 저장**: 컨트롤러의 `/json/eff`, `/json/pal` 목록을 붙여 두면 프롬프트에 자동으로 들어갑니다.
- **AI 답 검사기**: AI의 답을 통째로 붙이면
  - ```` ```json ```` 코드 블록 표시와 휜 따옴표(“ ”)를 자동으로 고치고
  - JSON 문법 오류를 알려 주고
  - 밝기(`bri`)를 150 이하로 맞추고
  - 효과 번호(`fx`)가 우리 목록에 있는지, 어떤 효과 이름인지 보여 줍니다.
  - 마지막으로 WLED 프리셋의 **API command** 칸에 붙여 넣을 깨끗한 한 줄을 만들어 줍니다.

### 📦 남은 박스 설치·결선
- 박스 방향 규칙 6가지, 한 박스 다는 순서(장착 → 기록 → 한지 → 배선 → 확인)
- 결선 실수가 나는 세 곳(단자대, 끝단 급전선, 덜 꽂힌 JST) 그림
- **결선 체크리스트**: 체크한 상태가 기기에 남고, 진행 막대로 보입니다. "다음 박스" 버튼으로 초기화합니다.

### 🔦 고장 사냥
- 막혔을 때 다섯 단계: 멈춘다 → 증상을 말한다 → 후보를 모은다 → 하나씩 확인한다 → 한 문장으로 남긴다
- **증상 고르기**: 14가지 증상 중 하나를 누르면 먼저 볼 곳과 확인 순서가 나오고, 가이드북의 해당 항목으로 이어집니다.
- 반으로 나눠 찾기(이분 탐색): 100개도 7번이면 찾습니다.

### 🩺 고장 17가지
가이드북의 고장 항목은 **증상 · 이유 · 해결** 형식이며, 분류(안 켜짐, 색·깜빡임, 순서, 접속, AI·프리셋)로 거를 수 있습니다. `playbook.html#e7`처럼 주소로 바로 열 수 있습니다.

## 작품 구성 (사이트에 적힌 기준값)

| 항목 | 내용 |
|---|---|
| 박스 | 약 100개, 17열 × 6단 원형 배치, 한쪽은 관람객 입구 |
| LED | 12V WS2811 노드 100개 = 4구간 × 25개, 노드 사이 JST 3핀 |
| 컨트롤러 | ESP32 + WLED 4채널, 링 뒤쪽 가운데에 숨김 |
| 전원 | 12V 20A 어댑터 1대, 구간 끝단 급전 |
| WLED 접속 | 와이파이 `WLED-AP` / 비밀번호 `wled1234` / 주소 `http://4.3.2.1` |

> 실제 설치 장소에서 열·단 수, 접속 정보, 선 색이 달라지면 `index.html`, `workbench.html`, `playbook.html`의 해당 문장을 고쳐 주세요.

## 안전 원칙

- 학생은 **12V 쪽만** 만집니다. 콘센트·어댑터 플러그·멀티탭(220V)은 선생님만 다룹니다.
- 모든 결선은 전원이 꺼진 상태에서 하고, 전원은 선생님이 확인한 뒤 켭니다.
- WLED의 LED 수·출력 핀·색 순서 설정은 학생이 바꾸지 않습니다.

```

├── index.html       홈
├── workbench.html   실습 워크벤치
├── playbook.html    초보 가이드북

- 글꼴은 Google Fonts(고운바탕, IBM Plex Sans KR)를 불러오며, 연결이 안 되면 기본 글꼴로 보입니다.

## 데이터 저장과 개인정보

- 체크리스트, 붙여 넣은 효과·팔레트 목록, 마지막으로 적은 장면은 **각 학생 기기의 브라우저(localStorage)에만** 저장됩니다.
- 서버나 다른 사람에게 전송되는 정보는 없습니다. 로그인도 필요 없습니다.
- 사이트에서 학생에게 AI 프롬프트에 이름·학교·사진 같은 개인정보를 넣지 말라고 안내합니다.

## 깃허브 페이지에 배포하기

1. github.com에서 **New repository** → 이름(예: `led-stage-kit`) → **Public**으로 만듭니다.
2. **uploading an existing file**을 눌러 이 폴더 안의 파일들을 저장소 맨 위에 올리고 **Commit changes**를 누릅니다. (폴더째 올리지 않습니다.)
3. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다. 이 README 맨 위의 주소도 실제 주소로 바꿔 주세요.
