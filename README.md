# 빛으로 짓는 인생의 무대 — 학생용 키트

이사벨여고 LED 조명 설치 수업 뒤에 학생들이 스스로 효과를 바꾸고, 남은 박스를 달고, 고장을 고칠 수 있도록 만든 사이트입니다.

| 파일 | 내용 |
|---|---|
| index.html | 홈: 하려는 일 고르기, 작품 평면도, 안전 수칙 |
| workbench.html | 실습 워크벤치: 프롬프트 만들기, AI 답 검사기, 설치 체크리스트, 증상 고르기 |
| playbook.html | 초보 가이드북: WLED 접속, 프리셋 저장, 고장 17가지(증상·이유·해결) |
| style.css · common.js · workbench.js | 공통 스타일과 스크립트 |

## 깃허브 페이지에 올리기
1. 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (폴더째가 아니라 파일들을 저장소 맨 위에).
2. Settings → Pages → Branch를 `main` / `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

체크리스트와 붙여 넣은 효과 목록은 각 학생 기기의 브라우저에만 저장됩니다(서버 저장 없음).
